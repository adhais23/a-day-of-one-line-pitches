One sentence, 216 characters, that would convince a friend who has never
coded to let an AI agent build their first app idea on make.fun.

> Just describe the app idea you've been carrying around in plain words, and an AI agent on make.fun will build the first version for you — no coding, nothing to lose, and you'll finally get to tap through it yourself.

The program (`main.py`, Python standard library only, no network) writes
that sentence to `/output/entry.txt`. It is deterministic: every run
writes the same text.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
